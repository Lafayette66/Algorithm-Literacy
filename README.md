# Algorithm Literacy Hub — workshop prototype

Static prototype for the Algorithm Literacy for Older Adults design workshop
(Northeastern University, College of Arts, Media, and Design).

| Page | File |
|---|---|
| Home | `index.html` |
| Learn | `learn.html` |
| Get help | `get-help.html` |
| Profile | `profile.html` |
| Card sorting activity (not linked from the hub; share the URL directly) | `sorting.html` |

Everything is static: no data is sent anywhere. The sign-in form and booking form are demos.
